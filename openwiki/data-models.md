# Data Models

Midas Touch stores its core business data in **PostgreSQL** with the help of SQLAlchemy ORM models defined in `shared/database/models/postgres_models.py`. Certain high‑dimensional vectors (embeddings, analysis memory) use the `pgvector` extension (column type `Vector(1024)`).

---

## Core Tables

| Table | Purpose | Key Columns |
|-------|---------|-------------|
| **users** | User profile & investment preferences. | `id` (UUID PK), `uuid` (string), `age`, `sex`, `education_level`, `total_amount`, `monthly_income`, `aggressiveness`, `preferred_asset` |
| **portfolios** | A collection of portfolio allocations belonging to a user. | `id` (UUID PK), `user_id` (FK → users.id), `name`, `stock_ratio`, `bond_ratio`, `real_estate_ratio`, `gold_ratio`, `cash_ratio`, `is_active` |
| **portfolio_items** | Individual asset entries within a portfolio. | `id` (UUID PK), `portfolio_id` (FK → portfolios.id), `asset_type`, `ticker`, `allocation_pct`, `currency` |
| **tax_rules** | Korean tax regulation data used for after‑tax calculations. | `id` (PK), `asset_type`, `income_type`, `tax_rate`, `effective_date` |
| **market_snapshots** | Time‑series market data (indices, FX, yields) fetched by the ingestion pipeline. | `id` (PK), `snapshot_date`, `data_type`, `sub_key`, `value`, `unit`, `source` |
| **legal_references** | Legal source documents for tax rules. | `id` (PK), `description`, `legal_basis` |
| **news_embeddings**, **strategy_docs**, **macro_indicators**, **persona_embeddings** | Vector embeddings (pgvector) for RAG and persona‑based recommendations. Each has a `Vector(1024)` column named `embedding`.
| **chat_sessions** | Metadata for multi‑turn chat conversations persisted by the LangGraph `PostgresSaver`. | `session_id` (PK), `user_uuid`, `title`, `message_count`, `updated_at` |
| **graph_checkpoints** | Tracks incremental Neo4j graph builds to avoid re‑processing already‑ingested passages. | `id` (PK), `completed_at`, `snapshot_path` |
| **analysis_memory** (implicit) | Past stock analysis snapshots stored as JSONB (see `backend/app/services/trading/analysis_memory.py`). Not a dedicated table – stored in a generic JSON column of a dedicated model (see source).

---

## pgvector Columns

The following models contain a `Vector(1024)` column (requires the `pgvector` extension):

* `NewsEmbedding.embedding`
* `StrategyDoc.embedding`
* `MacroIndicator.embedding`
* `PersonaEmbedding.embedding`

These vectors are generated by the **embedding pipeline** (`pipelines/embedding/`) and are queried with cosine similarity for RAG tools like `persona_rag`.

---

## How to Extend the Schema

1. Add a new model class inheriting from `PostgresBase` in `shared/database/models/postgres_models.py`.
2. Run `alembic revision --autogenerate -m "add <table>"` and then `uv run alembic upgrade head` to apply migrations.
3. Update the corresponding repository in `shared/database/repositories/` to expose CRUD helpers.
