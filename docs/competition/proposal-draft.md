## 1. 문제(현안) 정의

### 1.1 현안 ① — 금융 정보 파편화와 정보 격차
- 세법은 **매년 개정**된다: 기획재정부가 매년 7월 세법개정안을 발표해 국회 심의를 거치며, 2024년 한 해에만 15건의 세법개정안이 국회에 제출·심의됐다(국회예산정책처). 청약·연금·ISA·연말정산 제도는 각기 다른 기관 사이트에 파편화돼 있어 개인이 스스로 종합하기 어렵다.
- 정보를 해석할 수 있는가가 곧 자산 격차로 이어진다. 2025년 가계금융복지조사(한국은행·국가데이터처, 2025.12) 기준:
  - 가구주 39세 이하 가구의 평균 자산은 3억 1,498만 원으로 **전 연령대 중 유일하게 감소(-0.3%)** — 같은 기간 전체 가구 평균 자산은 +4.9%, 40대는 +7.7% 증가.
  - 장기 추세 격차도 확대: 2017년 대비 자산 증가율이 전체 평균 +46.6%인 반면 청년층은 +20.7%에 그침(40대는 +57.2%). 소득 증가율 역시 청년층이 최하위(+1.4% vs 전체 +3.4%).
  - 청년층 내부에서도 격차가 벌어진다: 자본시장연구원 분석(2025)에 따르면 청년 소득 상위 20%와 하위 20%의 금융자산 규모 차이는 2019년 약 3.7배에서 지속 확대됐고, 저소득 청년층의 투자 참여율은 오히려 감소.
- 전문가(세무사·재무상담) 상담은 비용·심리적 진입장벽이 커서, 디지털 채널로 1차 상담을 대체할 수 있는 서비스가 부재하다. → 정보 해석 능력이 있는 층만 혜택을 보는 구조.

### 1.2 현안 ② — 생성형 AI '환각'과 금융 소비자 보호
- 범용 AI 챗봇에 세율·법령·상품을 물으면 **그럴듯하지만 틀린 답**(hallucination)을 내놓을 수 있고, 근거가 공개되지 않아 소비자가 검증할 방법이 없다. 실제 사례:
  - 조세일보(2026.4): 범용 빅테크 AI는 생계형 창업중소기업 세액감면 제도를 "없는 제도"라고 오답, 주택 임대소득 간주임대료 이자율도 구세법 기준 2.9%로 답함(개정 반영 정답 3.1%). 국세청은 이에 대응해 생성형 AI 챗봇을 시범 운영 중.
  - 중앙일보(2026.6): AI가 작성한 금융 민원서에 **존재하지 않는 판례와 사건번호까지 환각**되어 첨부되는 일이 빈번해 금감원이 금융사에 민원 감축 계획 제출을 요청.
  - 디지털투데이(2026.5): 영국 회계업계 조사에서 회계사·부기 담당자 절반이 "기업이 AI의 잘못된 재무 조언을 따르다 손실을 본 사례"를 경험.
  - 국내 인터넷은행 AI 상담도 DSR 계산에 전세대출 원금을 포함하는 등 오류로 실제 대출 한도와 엇갈리는 결과 보도(서울경제, 2026.4).
- 금융권 생성 AI 도입이 가속되는 만큼 "AI 조언을 누가, 어떻게 검증하는가"는 새로운 소비자 보호 현안이다.
- 즉 본 프로젝트가 겨냥하는 것은 "AI가 없어서"도 "AI가 많아서"도 아니며, **"믿을 수 없어서 생기는" 금융 정보 격차**다.

### 1.3 타깃 고객과 서비스 채널
- **누구**: 투자 경험이 얕은 청년·사회초년·1인 가구 직장인 (재테크 욕구는 있으나 세법·제도 해석 능력 부족).
- **어디서**: 모바일 우선 웹앱 — 설치 없이 접속해 **대화형 채널**로 시작하고, 깊이 필요할 때만 대시보드·그래프로 확장되는 UX.
- **어떻게**: 익명 페르소나(나이·소득·성향)만으로 개인화가 시작되므로 진입장벽이 낮다.

## 2. 솔루션 개요

### 2.1 접근 — "통합"의 재정의
단순한 기능 번들이 아니라, **허브-스포크 구조**다:

```
        ┌──────────── 대화형 AI 에이전트 (허브) ────────────┐
        │   사용자 프로필(persona)을 아는 단일 진입점          │
        └──┬─────────┬─────────┬─────────┬─────────┬──────┘
     주식분석·    세법 근거    청약       시장      또래 벤치마킹
     백테스트    지식그래프   알리미    대시보드    (persona RAG)
```

사용자는 하나의 대화로 모든 상담을 끝내지만, 각 답변은 전용 화면(스포크)으로 **깊어질 수 있다**. 5개 창구를 오케스트레이션하는 것이 "나를 아는 하나의 어드바이저"다.

### 2.2 핵심 기능 ↔ 현안 매핑

| 현안 | 해결 기능 | 사용자가 체감하는 변화 |
|---|---|---|
| 정보 파편화 | AI 챗봇 통합 상담 (`/chat`) | 세금·시장·청약을 한 대화창에서 |
| 맞춤형 부족 | 페르소나 프로필 + 또래 벤치마킹 (persona RAG) | "나 같은 사람은 어떻게 하는지" 비교 |
| 근거 불투명 | 세법 지식그래프 (`/graph`) + 출처 표기 RAG | 답변 뒤의 법령 원문까지 클릭 추적 |
| 판단 도움 | 주식 기술지표 진단 + 전략 백테스트 (`/stocks`) | 감이 아니라 과거 데이터로 검증 |
| 청약 정보 격차 | 청약 알리미 (`/cheongyak`) | 공공데이터 실시간 공고·경쟁률 한눈에 |

### 2.3 대표 사용자 여정 (3 시나리오)

**A. "월급쟁이 민준(34, 직장인)"의 종합 재테크 상담**
1. 페르소나 선택 → 대시보드에서 자산 배분 확인
2. 챗에서 "연말정산 때 놓치면 아까운 공제 알려줘" → 프로필 반영 답변
3. "그 근거 법령이 뭐야?" → `/graph`에서 조항 원문 확인
4. "나와 비슷한 사람들의 포트폴리오는?" → persona 유사도 검색 결과

**B. "내집마련 지수(29)"의 청약 탐색**
1. `/cheongyak`에서 지역별 마감 임박 공고 조회 (공공데이터 실시간)
2. 챗에서 "이 단지 당첨 가점 몇이면 안정적이야?" → 가점 산정 정보 + 특별공급 조건 안내

**C. "검증하는 서연(31)"의 투자 판단**
1. `/stocks`에서 관심 종목 RSI·MACD 자동 진단
2. 이동평균 교차 전략을 과거 데이터로 백테스트 → 수익률·MDD 확인 후 판단
3. 챗에서 AI의 종목 코멘트를 받되, **과거 AI 예측의 실제 적중률**이 기록·공개됨(§3.4)

### 2.4 차별점 비교

| 축 | 범용 AI 챗봇 | 로보어드바이저 | **Midas Touch** |
|---|---|---|---|
| 답변 근거 공개 | ✕ (블랙박스) | 부분 (모델 로직) | **✓ 법령 그래프 + 문서 passage 단위 출처** |
| 개인화 | 대화 내 한정 | 리스크 설문 기반 | **✓ 프로필 + 유사 투자자 집단 벤치마킹** |
| 자기 검증 | ✕ | 백테스트 일부 | **✓ AI 예측→실현수익률 자가 채점 루프** |
| 상담 범위 | 범용 | 투자 배분 중심 | **✓ 투자+세법+청약 통합** |

> 시장 맥락: 세법 지식그래프를 활용한 AI는 이미 등장했으나(더존 '엑스퍼트원' 등) 전부 **세무사 등 B2B 전문가 대상**이다. 본 서비스는 동일한 신뢰 아키텍처를 **일반 금융소비자(B2C)**에게 — 대화 채널·무료·개인화로 푸는 것이 차별점이며, 포용금융 관점에서 정보 격차 해소를 겨냥한다.

## 3. AI 신뢰 아키텍처 — "환각 없는 금융 AI" (핵심 차별화)

> 이 섹션이 본 기획서의 승부처입니다. "왜 이 AI는 믿을 수 있는가"에 5겹의 방어로 답합니다.

### 3.1 결정적 오케스트레이션 (LangGraph)
- 무분별한 ReAct 루프 대신 **intent 분류 → 필요한 도구만 병령 fan-out → 단일 synthesize 호출** 구조로, 도구당 LLM 호출을 1회로 압축해 지연·비용을 절감. `[ ]` ReAct 대비 실측 지연/토큰 절감 수치 보강 가능.
- LLM이 지어낸 도구 이름은 화이트리스트에서 차단 → 프롬프트 인젝션의 도구 남용 경로 완화.

### 3.2 근거 그래프 (GraphRAG)
- 세법·절세 전략을 엔티티 그래프(Neo4j)로 구축하고, 답변 생성 시 참조한 법령·세율의 **원문 서브그래프를 `/graph` 화면에서 시각적으로 추적** 가능. "AI가 왜 그렇게 말했는지"가 UI에 존재한다.
- 이 접근의 유효성은 제3자 검증으로도 뒷받침된다: 세법 지식그래프 탐색 에이전트는 2024년 세무사 1차 시험 '세법학 개론'에서 범용 LLM(GPT-4, 24.1점 낙제) 대비 86.2점을 기록 — 세법처럼 계층적으로 얽힌 지식은 단순 RAG보다 그래프 탐색이 본질적으로 유리하다(텍스워치, 2025.12).

### 3.3 출처 강제 RAG
- 국세청 문서를 passage 단위로 검색해 답변 컨텍스트에 **출처(passage id·source)를 강제 표기**, 컨텍스트에 없는 수치의 생성을 금지하는 grounding 지시를 항상 시스템 프롬프트에 삽입.

### 3.4 자가 캘리브레이션 루프 (해자)
- AI의 종목 분석(매수/매도/관망 + 확신도)을 메모리에 저장하고, 시간 경과 후 **실현 수익률로 자동 채점**한다.
- 측정: 모델 적중률 vs 상수전략 baseline(항상 BUY/SELL/HOLD), 확신도(high/medium/low)↔실제 적중률 단조성(캘리브레이션 곡선).
- 의미: **"이 AI 말이 맞았는지"를 AI 스스로 성적표로 공개** — 생성형 AI 금융 서비스의 책임성 문제에 대한 구조적 답변이며, 데이터가 쌓일수록 강해지는 축적형 해자다.
- 초기 실측 (소급 시딩 기반 초기 실측, n=50 — 국내·미국 대형주 10종 × 최근 9~3개월 5시점을 과거 시점 데이터만으로 재분석해 적재, 라이브 트래픽 아님): validate_calibration_moat.py 실행 결과 모델 적중률 72.0% vs 최고 상수전략(always_HOLD) 72.0% → edge +0.0%p로 노이즈 범위(1.96·SE≈12.4%p). 확신도가 전부 medium으로 상수라 캘리브레이션 곡선 판정 불가. 즉 루프·채점기는 실측됐으나 해자(edge)는 아직 미입증 — 라이브 데이터 축적 후 재측정이 필요한 정직한 출발점.

### 3.5 안전 설계
- SSRF 방지(외부 fetch 허용 호스트 검증), JWT+bcrypt 인증, DB 전 구간 파라미터 바인딩, API 키 미설정 시 서비스 저하(graceful degrade), 투자자문이 아닌 정보 제공임을 명시하는 면책 프레이밍.

## 4. MVP 구현 현황 (기능명세서와 일치)

| 기능 | 구현 상태 | 비고 |
|---|---|---|
| 대화형 상담 (`/chat`) | ✓ SSE 실시간 스트리밍 | LangGraph 체크포인트로 멀티턴 영속화, 답변 말미 출처 자동 표기 |

| **사기 메시지 검증** (챗 도구) | ✓ | 보이스피싱·리딩방 휴리스틱 스코어링 + 웹검색 보강, 신고 안내 포함 |
| 청약 알리미 (`/cheongyak`) | ✓ | 한국부동산원 공공데이터 실시간 |
| 세법 지식그래프 (`/graph`) | ✓ | Neo4j GraphRAG 시각화 |
| 대시보드 (`/dashboard`) | ✓ | 시장 지표 + 페르소나 배분 비교 |
| AI 예측 자가검증 루프 | ✓ | 예측 저장→실현수익률 채점→baseline 비교 (§3.4 초기 실측) |
| 데이터 파이프라인 3종 | ✓ | 수집 / 임베딩 / 지식그래프 빌더 |
| 품질 | ✓ | 테스트 107건, CI(ruff·pytest·tsc·eslint) |

## 5. 기술 아키텍처 요약

- **Frontend**: Next.js 16(App Router), TypeScript, Tailwind, GSAP/D3/WebGL 시각화
- **Backend**: FastAPI, LangGraph(StateGraph + PostgresSaver 체크포인터)
- **AI**: NVIDIA NIM(gpt-oss-120b / bge-m3 임베딩), Tavily·Naver 웹검색 도구
- **Data**: PostgreSQL(pgvector) · Neo4j · yfinance · 청약홈 공공데이터
- **Infra**: Docker Compose, Alembic 마이그레이션, GitHub Actions CI
- 전체 다이어그램: `architecture.svg` 참조

## 6. 기대 효과 및 확장 로드맵

| 단계 | 내용 | 대회 주제와의 연결 |
|---|---|---|
| 현재(MVP) | 통합 상담 + 근거 공개 + 결정론적 계산 + 사기 검증 + 자가 검증 | 맞춤형 금융 AI, 소비자 보호, 이상금융거래 |
| Phase 2 | 캘리브레이션 라이브 데이터 축적·재측정, 피싱 패턴 정기 갱신 파이프라인 | AI 책임성·금융 보안 고도화 |
| Phase 3 | 외국인 근로자 금융 정착 다국어 모드, 고령층 음성 친화 UI | 포용적 금융서비스 |
| Phase 4 | 실제 고객 코호트 제휴 시 또래 비교 고도화 (현재 또래 데이터는 합성 페르소나임을 UI에 명시) | 데이터 거버넌스 투명성 |

> **정직성 원칙**: MVP의 페르소나·또래 비교 데이터는 LLM 합성 데이터이며 UI·기획서에 이를 명시한다. 심사 신뢰도는 과장이 아니라 고지에서 나온다.
